# Hello World

欢迎来到 **Woods' Blog**！🎉

这是我在这个博客里面的第一篇博客文章。创建这个博客的初衷很简单——**记录**和**分享**。在这里，我会分享技术文章、生活感悟，以及日常的一些碎碎念（当然没有纯水，纯水去看QQ空间）。

---

## 为什么写博客？

啊，这是一个非常值得思考的问题，写博客对我来说有以下几个意义：

1. **知识沉淀** — 把学到的东西写下来，加深理解，也方便日后查阅，虽然现在都用AI了
2. **帮助他人** — 也许我的经验能帮到遇到同样问题的人
3. **锻炼表达** — 写作是思考的延伸，写清楚才能想清楚；还有就是我的语文特别差，正好可以锻炼一下
4. **留下痕迹** — 互联网上的文字，是存在过的证明

## 这个博客有什么？

### 📝 文章

技术文章和生活随笔，涵盖程序开发、工具使用、学习笔记等。每篇文章都支持 Markdown 渲染，包括代码块、表格、引用、链接等格式。

### 💬 说说

类似QQ空间的简短日常记录，支持文字和图片。不想写长文的时候，就在这里记录一下当下的心情。

### 🔍 搜索

支持实时搜索文章标题、内容和标签，快速找到你感兴趣的内容。

### 🏷️ 标签与归档

文章按标签分类，也支持按年份归档浏览，方便回顾历史内容。

### 💬 评论

基于 GitHub Issues 的评论系统（Utterances），无需后端服务即可实现评论功能，因为项目纯前端，不想花钱买服务器。

### 🌙 暗色模式

支持亮色/暗色主题切换，跟随系统设置或手动切换，保护眼睛。

### 🌐 多语言

支持中文和英文双语切换，内容同步维护。

## 技术栈

这个博客完全由前端技术构建，是一个纯静态站点：

| 技术 | 用途 |
|------|------|
| [Nuxt 3](https://nuxt.com/) | 通用框架，支持 SSR 和静态生成 |
| [Vue 3](https://vuejs.org/) | 响应式 UI 框架 |
| [Tailwind CSS](https://tailwindcss.com/) | 原子化 CSS，快速构建界面 |
| [Markdown-it](https://github.com/markdown-it/markdown-it) | Markdown 解析与渲染 |
| [Utterances](https://utteranc.es/) | 基于 GitHub Issues 的评论系统 |
| [Cloudflare Pages](https://pages.cloudflare.com/) | 静态站点托管与部署 |

### 架构特点

- **纯静态** — 所有内容以 Markdown 文件存储，构建时生成静态 HTML，无需数据库
- **SSG 静态生成** — 使用 Nuxt 3 的 `nuxt generate` 生成静态文件，部署简单
- **响应式设计** — 基于 Tailwind CSS，适配桌面端和移动端
- **国际化** — 中英文内容分离存储，运行时按语言加载
